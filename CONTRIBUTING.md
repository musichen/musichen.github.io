# Contributing to musichen.github.io

This is a plain static GitHub Pages site with no build step.

## Test locally

```bash
python3 -m http.server
# then open http://localhost:8000
```

Open the page you changed (`index.html`, or the folder under `apps/`, `webapps/`, `tools/`, `games/`, or `blog/`) and click through its links.

## Pull requests

Create a branch from `master`, keep changes to plain HTML, CSS, and JS that work when served statically, and say which pages you opened locally in the PR.
