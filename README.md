# musichen.github.io

Alexander Musichen github webpage: the personal GitHub Pages site for [github.com/musichen](https://github.com/musichen).

## Contents

Static pages and mini-apps served as plain files, including:

- `apps/`, `webapps/`, `tools/`, and `games/` - small web tools and experiments
- `blog/` - blog pages
- `2048/` - the 2048 game
- `ip/` and `qr.pdf` - utility pages and assets

## Run locally

No build step. Serve this folder with any static file server and open `index.html`:

```bash
python3 -m http.server
# then open http://localhost:8000
```
